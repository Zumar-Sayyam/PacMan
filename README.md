# Pac-Man Console Game in Java

A simple console-based Pac-Man game developed using Java and Object-Oriented Programming concepts.

---

# Features

- Pac-Man movement using keyboard
- Random moving ghosts
- Custom maze generation using logic
- Food collection system
- Score tracking
- Game Over detection
- Winning condition

---

# Technologies Used

- Java
- OOP Concepts
- Arrays
- Interfaces
- Random Class
- Scanner Class

---

# Controls

| Key | Action |
|-----|--------|
| W | Move Up |
| A | Move Left |
| S | Move Down |
| D | Move Right |
| Q | Quit Game |

---

# Game Symbols

| Symbol | Meaning |
|--------|---------|
| P | Pac-Man |
| G | Ghost |
| # | Wall |
| . | Food |
